# Breast Cancer Detection (CSE422)

This project focuses on detecting breast cancer using machine learning algorithms. We utilize a dataset to train and evaluate multiple models, including KNN, SVM, Decision Tree, and Logistic Regression.

## Project Overview

- **Dataset**: Breast Cancer Dataset (processed from Kaggle).
- **Goal**: Successfully address medical concerns using AI technologies through data cleaning, preprocessing, encoding, and model comparison.
- **Evaluation**: Models are assessed using Precision, F1 Score, Recall, Accuracy, and Confusion Matrix analysis.

## Getting Started

Follow these steps to set up and run the project locally.

### 1. Clone the Repository
```bash
git clone https://github.com/YAdnan408/Breast-Cancer-Detection-CSE422.git
cd Breast-Cancer-Detection-CSE422
```

### 2. Set Up a Virtual Environment (Recommended)
```bash
python -m venv venv
# On Windows
.\venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Project
The main logic is contained within the Jupyter Notebook. You can launch it using:
```bash
jupyter notebook Group10_Project.ipynb
```
